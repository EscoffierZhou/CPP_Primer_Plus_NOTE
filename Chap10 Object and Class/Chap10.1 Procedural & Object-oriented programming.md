# Chap10.1 Procedural & Object-oriented programming

**过程性编程方法**

>   首先考虑遵循的步骤,然后考虑如何表示这些数据
>
>   (不需要程序一直运行,因为数据的位置会随时变动)

**面向对象的方法**

>   首先考虑数据(如何表示数据/如何使用数据)
>
>   需要处理该对象的方法,该对象的基本信息,执行方法(用户接口)
>
>   用户对数据交互的方法:初始化/更新/报告

总之，采用OOP方法时，首先从用户的角度考虑对象——**描述对象**
**所需的数据以及描述用户与数据交互所需的操作**。完成对接口的描述
后，需要确定**如何实现接口和数据存储**。最后，使用新的设计方案创建
出程序。
