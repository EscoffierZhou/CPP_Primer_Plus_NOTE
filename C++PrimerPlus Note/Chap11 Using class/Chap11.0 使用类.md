>   如果函数使用常规参数而不是引用参数将会发生什么

>   如果忽略了析构函数将会发生什么

然后本章首先介绍**运算符重载**，它允许将标准C++运算符（如=和+）用于类对象。然后介绍**友元**，这种C++机制使得非成员函数可以访问私有数据。最后介绍如何命令C++对类执行自动类型转换。学习本章和第12章后，您将对类构造函数和类析构函数所起的作用有更深入的了解。另外，您还将知道开发和改进类设计时，需要执行的步骤。
